# Design System

Direction: premium, calm health dashboard; not a gym-bro aesthetic.

Colors:
--bg #F7F8F5
--surface #FFFFFF
--primary #183B2B
--accent #B8D98A
--text #18221D
--muted #68736C
--border #E5E9E4
--warning #C98A2E
--danger #B64B4B

Typography: Inter/system sans.
Components: AppShell, StatCard, MealCard, MealSwapModal, JournalSheet, TrendCard, InsightCard, GroceryGroup, WHOOPUpload.

Desktop nav: Dashboard / Plan / Journal / Insights / Grocery / WHOOP / Profile
Mobile nav: Home / Plan / Journal / Insights / More

UX:
- One-tap meal logging.
- Two-tap meal swapping.
- Night journal <60 seconds.
- Always show why recommendations changed.
- Never hide nutrition constraints.
