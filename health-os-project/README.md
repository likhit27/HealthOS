# HealthOS
Free-first personal meal planner, meal recorder, gut journal, WHOOP tracker and health intelligence app.

## Stack
Next.js + TypeScript + Tailwind + Supabase + Vercel.
V1 intelligence is rule/statistics based, so there is no paid AI dependency.

## Run
npm install
npm run dev

Then open http://localhost:3000

Copy .env.example to .env.local for Supabase when ready.
