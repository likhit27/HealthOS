# Product Specification

Core loop:
Profile → Weekly Plan → Eat → Nightly Journal → Analyze → Improve → Monthly WHOOP upload.

Modules:
1. Profile: weight, height, goal, diet, exclusions, protein/calorie targets.
2. Weekly planner: 7-day plan, nutrition totals, meal swapping, hard constraints.
3. Meal recorder: done / partial / missed.
4. Night journal: gas, pain, bowel status, energy, stress, weight, notes.
5. Intelligence: adherence, weight trend, food-tolerance associations, recovery trends.
6. WHOOP: monthly ZIP upload, normalized daily metrics.
7. Grocery: aggregate ingredients and generate cook list.

Your current defaults:
- Mostly vegetarian
- Tuesday pure vegetarian
- Lunch/dinner no dal
- Protein target 90–100g
- Calories initially ~2,100–2,300
- Max eggs/day initially 4
- Goal: gradual weight gain + muscle
