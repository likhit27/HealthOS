# Deploy to Vercel

1. Push this folder to GitHub.
2. Import repository in Vercel.
3. Framework: Next.js.
4. Build: `npm run build`.
5. No environment variables required for local-first mode.
6. Test Dashboard, Plan, Tuesday constraint, meal swaps, meal logging, Close My Day, Insights, Grocery and Profile.
7. Run `supabase/schema.sql` in Supabase when ready for cloud persistence.
