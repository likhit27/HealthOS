# HealthOS Phase 1–5

A free-first personal health OS for weekly meal planning, nutrition-aware swaps, meal logging, nightly journaling and rule/statistics-based health intelligence.

## Run
npm install
npm run dev

## Vercel
Import this project. No environment variables are required for the local-first demo. Supabase schema is included for the cloud-persistence step.

## Included
Phase 1 UI · Phase 2 personalization · Phase 3 nutrition-aware swaps · Phase 4 journal · Phase 5 intelligence.
