# HealthOS Phase 1–5

1. UI: Dashboard, weekly plan, swaps, journal, insights, grocery, profile.
2. Personalization: profile-driven calorie/protein/fibre targets, Tuesday pure vegetarian, no dal at lunch/dinner, gut-friendly filter.
3. Smart swaps: compatible alternatives plus a second-slot rebalancing pass to reduce calorie/protein/fibre error.
4. Journal: meal completion + gas/pain/energy/stress/bowel/weight/notes.
5. Intelligence: adherence, digestion baseline, weight direction and planned-protein insights.

The app is local-first so it runs on Vercel without paid services. Supabase schema is included for cloud persistence/auth in the next integration step.
